# 02: 物理流引擎边界 PlaybackErrorKind 归一映射与容错解耦

**What to build:** 在领域模型与物理流引擎出口处建立强类型的播放故障分类接缝，消除应用级 `Playback Session` 容错逻辑对底层异常类的反向依赖与脆弱字符串猜测。引入覆盖文件缺失、认证失效、服务器不可达、不支持 HTTP Range 续传与未知故障的领域错误枚举并随错误状态向上传递；由物理流引擎在捕获底层播放异常时一次性解析因果链完成枚举映射，容错模块仅依据领域枚举分派自动跳曲、置错提示、连通性上报及不支持 Range 重播弹窗。

**Blocked by:** None (can start immediately)

**Status:** completed

- [x] 领域错误状态携带强类型故障分类枚举，现有错误构造调用方保持兼容
- [x] 物理流引擎出口统一将 HTTP 404/401/403、网络超时/连接拒绝及不支持 Range 异常精确映射为对应领域枚举
- [x] 会话容错模块彻底删除对底层流数据源异常类的反向导入与基于异常类名或状态码字符串的猜测分支
- [x] 物理流引擎错误映射单测、会话容错及端到端重播确认测试全部验证通过
