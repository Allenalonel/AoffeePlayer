# 03: 修复解绑目录前缀级联失效与删服内存缓存定向清理

**What to build:** 从存储管理表现层移除越界且重复的全库级联清理调用；完善目录缓存持久层与媒体库级联清理能力，使解绑单个 `Mounted Directory` 仅按对应树路径前缀清除目录缓存、检索索引、同步检查点与 `Browsing Cursor`（同时刷新根列表快照）并保留曲目元数据快照以保护跨源歌单的 `Inactive Playlist Track` 展示；同时在维持仓储单向依赖有向无环图的前提下，确保删除远程 `WebDavServer` 时同步定向失效元数据仓储内存中的歌词与目录封面缓存。

**Blocked by:** 01

**Status:** completed

- [x] 存储管理视图模型不再在删除服务器或解绑本地目录后额外调用媒体库级联清理接口，所有 `Storage Cascade Invalidation` 由存储源仓储单向触发。
- [x] 目录缓存持久层支持按存储源与路径前缀删除；解绑单个挂载本地文件夹时，兄弟挂载文件夹的目录缓存、索引、检查点及当前非子集游标均保持完好，且已入歌单曲目的元数据快照不被抹除。
- [x] 删除远程 WebDAV 服务器时，除磁盘封面与数据库记录外，元数据仓储内存中对应 `serverId` 的已解析歌词缓存与目录封面缓存同步定向失效，且不引入仓储层环形依赖。
- [x] 存储级联删除与视图模型相关针对性单测全部通过（含“挂两个本地目录解绑其一不伤及另一个”和“删服后重建同源不命中旧内存歌词/封面”的验证用例）。
