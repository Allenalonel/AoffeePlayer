# 05: 统一 TrackMetadataRepository 跨源批量校验与歌单封面自愈

**What to build:** 在元数据仓储对外开放面向规范 `TrackIdentity` 列表的批量元数据查询与跨源 `Cover Art Liveness Healing` 接口；彻底移除歌单仓储内部的逐首循环查库、磁盘封面存活性检查以及仅限本地的后台封面自愈任务，改为结合存储源可达性状态过滤出可用曲目后统一交由元数据仓储批量校验与跨本地/远程自愈，并将修复结果同步至歌单持久化快照。

**Blocked by:** 02, 04

**Status:** completed

- [x] 元数据仓储新增批量查询与存活性自愈契约，单次通过批量数据库查询获取多首跨源曲目元数据并校验磁盘封面文件物理存在性。
- [x] 对传入的可用曲目（同时涵盖 `Local Storage` 与远程 `WebDavServer`），元数据仓储在内部受限信号量与防重入任务表保护下统一后台重提取缺失或失效封面并回传/触发歌单快照更新。
- [x] 歌单仓储彻底清除循环单曲查询、本地物理文件存在判断与独立封面自愈协程，且确保处于不可达状态的 `Inactive Playlist Track` 绝不会触发网络自愈探测风暴。
- [x] 元数据仓储与歌单仓储针对性单测全部通过，验证远程与本地歌单封面损坏后均可自动自愈、离线曲目零探活且无 N+1 查库。
