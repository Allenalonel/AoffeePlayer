# 03: 全屏播放器多采样柔和氛围光晕重构

**What to build:** 重构全屏大播放器视图与 MiniPlayer 悬浮胶囊的背景色彩表现。告别单薄生硬的单色线性渐变下沉，在 28dp 方圆封面卡片后方构建基于 Palette 提取的多色 Swatch（Vibrant 活力主色 + Muted 辅助色）融合的多采样径向与网格氛围光晕，使全屏大封面呈现出录音室棚拍级的通透柔和微光；在黑白封面下呈现电影感十足的银灰烟雾质感；在低硬件开销下保障 120Hz 稳定满帧。

**Blocked by:** 01 (AndroidX Palette 依赖注入与 M3E 色彩推导引擎重构), 02 (全域主题音轨驱动与 450ms 流体色彩形变)

**Status:** ready-for-agent

- [ ] 多采样光晕构建：全屏播放器背景采用基于多色 Swatch 融合的径向氛围光晕，淘汰单色线性渐变。
- [ ] 封面呼吸感提升：28dp 方圆封面卡片后方形成与封面色彩同频共振的柔光投影，立体感显著增强。
- [ ] 黑白单色氛围保真：在播黑白音轨时，全屏背景呈现干净高冷的石墨/银灰烟雾流光，0 杂色。
- [ ] MiniPlayer 进度微光对齐：MiniPlayer 胶囊背景流体进度填充与新色调体系无缝融合。
- [ ] 渲染性能达标：全屏展开与滑动歌词期间 GPU 稳定 120Hz 满帧，无多层实时高斯模糊造成的性能惩罚。
