# 04: 跨源混编歌单、切歌过渡与对称失效自愈

**What to build:**
从用户视角出发，用户可以在自定义歌单中自由混合收录来自 WebDAV 云端服务器（如 OpenList、家庭 NAS）与手机本地存储的音频曲目。在媒体库通过长按多选或单曲操作，可将本地歌曲批量添加进已有歌单或新建歌单，底层自动执行跨源去重。播放一个包含网络歌曲与本地歌曲的混合歌单时，上一曲/下一曲流转、随机播放与插队播放（Play Next）均能够无缝平滑切歌，自动在网络流式管道与本地 I/O 管道之间安全过渡，杜绝爆音、卡顿或状态机死锁。同时严格遵循对称失效原则（Symmetric Fault Lifecycle）：若本地文件在外部被删除或 SD 卡拔出，歌单对应曲目优雅置灰并标注 `FILE_NOT_FOUND`；当文件放回或 SD 卡重新插入后，自愈网络自动检测并解除置灰。

**Blocked by:** 03: 本地音频极速直放管道、双源歌词与氛围流光联动

**Status:** resolved

- [x] 媒体库本地音频条目支持单曲“添加到歌单”与上下文多选批量收录，能够与已有的 WebDAV 曲目共同持久化在同一歌单中。
- [x] 批量添加本地曲目至歌单时，仓储层具备原子去重能力，准确提示新增与跳过歌曲数量。
- [x] 播放混合歌单时，播放队列在 WebDAV 曲目与本地曲目之间连续切歌、随机洗牌流转，音频解码与引擎过渡平滑无卡死。
- [x] 当本地文件物理不存在（外部删除或 SD 卡脱机）时，歌单列表内该曲目优雅显示为减淡置灰状态，点击弹出对应 Toast 提示，切歌时静默跳过。
- [x] 当缺失的本地文件恢复存在或 SD 卡重新挂载时，`triggerReachabilitySelfHealing` 自动检测并解除置灰，恢复可播高亮。
- [x] 歌单自定义排序（拖拽重排）、左滑插队与右滑删除对本地曲目表现一致。
